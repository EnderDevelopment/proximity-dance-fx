# Roblox Proximity Effects Script

Proximity Dance FX is a Roblox script for Roblox Studio that adds a local proximity particle effect to the player character. This Roblox script uses a LocalScript, detects nearby living players within 10 studs, and emits pink and yellow sparkles without sexual content, exploit behavior, animations, or interaction with another player's character.

## Install

1. Open the Roblox experience in Roblox Studio.
2. In Explorer, open `StarterPlayer`.
3. Open `StarterPlayerScripts`.
4. Add a `LocalScript` named `ProximitySparkles`.
5. Copy the contents of `StarterPlayerScripts/ProximitySparkles.client.lua` into the new LocalScript.
6. Test the experience with `Test > Start` and use at least two players.

## Use

1. Spawn into the experience.
2. Move within 10 studs of another living player.
3. The local character emits pink and yellow sparkles when another player is nearby.
4. The effect is checked every 0.25 seconds.
5. To customize the effect, edit `detectionRadius`, particle colors, texture, lifetime, speed, size, or emission count in `setupCharacter`.
6. The script automatically creates the effect again when the local character respawns.
